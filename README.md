# Marcher RU

Экспериментальный открытый движок русских шашек 8×8 для браузера.

Marcher RU объединяет **NNUE Marcher**, русский генератор ходов и поиск **Damka**, а также эндшпильные таблицы до пяти фигур. Все расчёты выполняются локально в Web Worker. Сервер анализа, аккаунт, Firebase и CDN для работы движка не нужны.

**Статус:** 0.1.0, экспериментальная адаптация. Рейтинг не измерен. Нейросеть Marcher обучалась на английских шашках; русская NNUE с нуля здесь не обучалась.

## Быстрый запуск

В репозитории уже есть собранные файлы в `dist/`. Для локальной демонстрации нужен только Node.js:

```sh
git clone https://github.com/xreamm1/Marcher-RU.git
cd Marcher-RU
node serve.mjs
```

Откройте **http://127.0.0.1:8081**. Демонстрация запускает Marcher RU против оригинального Damka с одинаковым лимитом времени; можно поменять цвета и смотреть реальную телеметрию.

Локальный HTTP-сервер обслуживает файлы с диска и не требует интернета. Открытие модульного примера двойным кликом через `file://` браузеры ограничивают.

Полная игра с шахматами, русскими шашками, друзьями и анализом: [chess-offline](https://xreamm1.github.io/chess-offline/).

## Подключение к своей игре

Скопируйте папку `dist` на свой сайт:

```js
import { MarcherRU } from './dist/client.js';
import * as Rules from './dist/rules.js';

const engine = new MarcherRU({
  onInfo(info) {
    console.log(info.depth, info.score, info.nodes, info.pv);
  }
});

let position = Rules.initial();
const result = await engine.analyze(Rules.toBitPosition(position), {
  engine: 'marcher-ru',
  depth: 32,
  movetime: 800
});

console.log(result.move); // полная серия: from, to, path, captures, promotes
position = Rules.apply(position, result.move);

// Оригинальный Damka для сравнения:
const opponent = await engine.analyze(Rules.toBitPosition(position), {
  engine: 'damka',
  depth: 32,
  movetime: 800
});

engine.dispose();
```

При другом расположении файлов передайте `baseUrl` — URL папки `dist/` с завершающим `/`.

### API клиента

- `ready()` загружает локальные ресурсы и таблицы. Можно дождаться отдельно; `analyze` вызывает его автоматически.
- `analyze(bitPosition, options)` возвращает Promise с ходом, оценкой и метриками. `engine`: `marcher-ru` или `damka`; `depth`: 1–40; `movetime`: 0–5000 мс. Ноль отключает таймер и используется для сравнения на фиксированной глубине.
- `stop()` отменяет запрос, завершает Worker и отклоняет Promise с `AbortError`. Следующий анализ создаёт Worker заново.
- `dispose()` освобождает ресурсы и закрывает клиент окончательно.
- Новый анализ отменяет предыдущий; устаревший ответ не подменяет результат нового запроса.

### Телеметрия

`onInfo` вызывается после завершённой итерации углубления:

| Поле | Что измерено |
|---|---|
| `engine`, `depth` | Активный движок и завершённая глубина |
| `score` | Оценка со стороны игрока, которому ходить; 100 — материал простой шашки в классической оценке |
| `nodes`, `time` | Число узлов и время поиска в миллисекундах |
| `pv` | Проверенные ходы продолжения, восстановленного из точных записей TT |
| `variants` | Корневые кандидаты, их оценки и границы: `1` — точная, `2` — нижняя, `3` — верхняя |
| `neuralCalls` | Число реальных обращений к NNUE; у оригинального Damka равно нулю |
| `ttHits`, `ttProbes` | Попадания и обращения к таблице поиска |
| `hashBytes` | Размер TT в байтах |
| `dbProbes`, `dbInflates`, `dbCacheBytes` | Обращения к базам, распаковки блоков и размер кэша |

Это данные алгоритма поиска. Человеческие рассуждения и полное дерево миллионов узлов движок не выводит.

## Архитектура

1. Русские ходы и полные серии взятий генерирует Damka.
2. Итеративное углубление, negamax/PVS, альфа-бета, aspiration windows, упорядочивание ходов, quiescence и TT также взяты из Damka.
3. Marcher экспортирует `_wasm_nnue_eval`; адаптер преобразует 32-клеточные битборды русских шашек в 64-битный формат Marcher и правильную перспективу цвета.
4. Английская NNUE даёт ограниченную позиционную поправку к русской оценке. Поправка ограничена ±100 единицами: русская цена дальнобойной дамки и точные результаты русских баз имеют приоритет.
5. При выборе `engine: 'damka'` NNUE-hook отключается. При переключении оценок очищается TT, чтобы записи другого движка не меняли результат.
6. Таблицы до пяти фигур загружаются в Worker. Сжатые блоки распаковываются по мере обращений.

Исходный C-поиск Marcher, английская дебютная книга и английские эндшпильные базы не используются. Это гибридная браузерная адаптация, а не полная переработка всех C-модулей Marcher.

Marcher WASM инициализируется только при первом запросе `marcher-ru`. Обычный Damka не несёт дополнительных расходов WASM. Runtime использует scalar-сборку для совместимости; специального COOP/COEP и SharedArrayBuffer не требуется.

## Правила

Реализованы обязательные взятия, бой простой назад, дальнобойные дамки, выбор полной серии без требования максимума, сохранение побитых фигур как препятствий до конца серии и превращение в дамку во время боя с продолжением серии.

В базовом движке используется упрощённая ничья Damka: **30 тихих полуходов дамками**. В демонстрации добавлено троекратное повторение позиции. Специальные турнирные лимиты по материалу не реализованы. Оригинальное описание сохранено в `vendor/damka/RULES.md`.

## Сборка из исходников

Node.js 22+, esbuild 0.25.11:

```sh
npm ci
npm run build
npm test
```

Сборка создаёт ESM-клиент и библиотеку правил, классический Worker, WASM Marcher и сжатый пакет русских эндшпильных таблиц. Ресурсы и исходники зависимостей сохранены в репозитории; исполняемому движку не нужен внешний CDN.

```text
src/client.js          Браузерный API и управление Worker
src/search.worker.ts   Выбор движка, NNUE-мост, таблицы и телеметрия
src/rules.ts           Публичный API русских правил
dist/                  Готовая браузерная сборка
vendor/damka/          Поиск, правила, тесты и эндшпильные данные Damka
vendor/marcher-ru/     Upstream WASM Marcher и его лицензия
index.html             Демонстрационный матч движков
```

## Проверки и сила игры

Проверены бой назад, дальнобойная дамка, обязательное взятие, выбор короткой/длинной серии, превращение внутри серии, неизменность исходной позиции и **perft глубины 6: 37 986 листьев**.

В интеграционном тесте исходной позиции на глубине 5 оригинальный Damka и режим `damka` дают одинаковый ход, оценку и точное число узлов. Вызовов NNUE — ноль. После поиска Marcher RU повторный поиск Damka даёт тот же результат: таблицы разных оценок не смешиваются.

Проверены браузерный поиск, последовательное переключение движков, отмена и автоматический матч с равными лимитами. Рейтинг Marcher RU не измерен. Победа в одной партии не доказывает превосходства: сравнивайте серию партий с обменом цветов и одинаковыми лимитами.

Следующий шаг для силы — обучение на русских шашках и воспроизводимый турнир против независимых движков.
